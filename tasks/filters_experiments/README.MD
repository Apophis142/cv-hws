# Filters & Edge Detectors Pipeline

Пайплайн для сравнения операторов выделения границ (Собель, Щарр, Прюитт, Кэнни) на медицинских изображениях (УЗИ и КТ) с предварительной фильтрацией (медианный или гауссов фильтр).

## Структура

```
.
├── tasks/
│   └── filters_experiments/
│       ├── main.py                    # точка входа
│       └── output/                    # результаты (создаётся автоматически)
├── data/
│   └── uzi_ct/
│       └── raw/                       # входные изображения
└── utils/
    ├── canny.py
    ├── color_transformation.py
    ├── filtering.py
    └── image_range.py
```

## Запуск

Из корня проекта:

```bash
python -m tasks.filters_experiments.main
```

С указанием своих путей:

```bash
python -m tasks.filters_experiments.main --input_dir path/to/images --output_dir path/to/output
```

### Аргументы

| Аргумент        | По умолчанию                              | Описание                          |
|-----------------|-------------------------------------------|-----------------------------------|
| `--input_dir`   | `data/uzi_ct/raw/`                        | Папка с исходными изображениями   |
| `--output_dir`  | `tasks/filters_experiments/output/`       | Папка для сохранения результатов  |

Поддерживаемые форматы: `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tif`, `.tiff`.

## Что делает скрипт

Для каждого изображения из `--input_dir` скрипт:

1. Читает изображение и переводит его из BGR в RGB.
2. Применяет предварительную фильтрацию двумя способами:
   - медианный фильтр (окно 7×7);
   - гауссов фильтр (окно 5×5, σ = 1.0).
3. К каждому отфильтрованному изображению применяет четыре оператора:
   - Собеля,
   - Щарра,
   - Прюитта,
   - Кэнни (пороги по умолчанию `0.03` и `0.11`).
4. Сохраняет **8 результатов** в подпапку с именем исходного файла:
   ```
   output/<имя_файла>/
   ├── sobel_median.png
   ├── sobel_gauss.png
   ├── scharr_median.png
   ├── scharr_gauss.png
   ├── prewitt_median.png
   ├── prewitt_gauss.png
   ├── canny_median.png
   └── canny_gauss.png
   ```

Для линейных операторов перед сохранением применяется логарифмическое растяжение контраста (`log_stretch`), иначе отклики фильтров почти неразличимы глазом из-за малой амплитуды реальных градиентов на УЗИ/КТ.

## Отчёт

По результатам визуального анализа восьми комбинаций на снимках УЗИ и КТ:

- **Гауссов фильтр** в разных конфигурациях фактически стирает почти все границы, кроме наиболее контрастных — например, границы снимка УЗИ. Мелкие и средне-контрастные структуры (в том числе контур почки) после него не выделяются.
- **Медианный фильтр** (7×7) ведёт себя заметно лучше: он подавляет шум, но сохраняет структурные границы. Однако на УЗИ даже после него настоящий контур почки плохо отделяется от шумов — граница почки по контрасту сопоставима с текстурой самого органа.
- **Собель, Щарр и Прюитт** дают визуально почти неразличимый результат. Разница между их ядрами сказывается на численных значениях откликов, но глазом без дополнительной обработки она не читается.
- **Кэнни** на УЗИ захватывает преимущественно шум: находится много мелких ложных контуров, а настоящая граница почки тонет в них. На КТ результат лучше, но сильно зависит от выбора порогов — при неудачных значениях либо теряется контур, либо изображение забивается ложными срабатываниями.

**Итоговая оценка комбинаций:** для УЗИ ни одна из пар «фильтр + оператор» не даёт чистого выделения почки; относительно лучший результат — медианный фильтр с линейными операторами, тогда как гауссов фильтр и Кэнни в текущих настройках практически бесполезны. Для КТ наиболее осмысленный результат даёт Кэнни, но только при ручном подборе порогов под конкретный снимок.
